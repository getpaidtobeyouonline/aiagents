Too Generic1The anyone testThe output is competent and completely interchangeable with anyone else in your niche.›
Type this to the agent
That could have been written for anyone in my niche. Rewrite it so only I could have written it — use the specific details from my context, not general statements about my industry.
Too Generic2Ask for the specific versionEvery sentence is technically true and none of them are about your business.›
Type this to the agent
Give me the specific version. Replace every general statement with something concrete from my business — a real number, a real product name, a real thing that happened.
Too Generic3Name the missing detailYou can feel what is missing but the output is not obviously wrong.›
Type this to the agent
This is missing anything that proves I have actually done this. Add one real example from my business to each point, and tell me which brackets I need to fill in if you do not have the detail.
Too Generic4Kill the safe adviceIt reads like a listicle you have seen fifty times.›
Type this to the agent
Cut every piece of advice that my audience has already read somewhere else. Keep only what is specific to how I do this, and tell me what you removed.
Too Generic5Demand the unpopular versionThe output agrees with everything and commits to nothing.›
Type this to the agent
This is too agreeable. Rewrite it taking a clear position that some people in my niche would disagree with — the one that matches what I actually believe from my context.
Too Generic6Force the exampleIt explains a concept without ever showing it.›
Type this to the agent
You explained it but never showed it. Add one concrete worked example — a real scenario with real numbers — and put it immediately after the explanation.
Wrong Voice7Re-read the voice guideThe output has drifted into polished AI English.›
Type this to the agent
Re-read my brand voice guide and rewrite that in my actual voice. Match the sentence length and the opening style, not just the friendliness.
Wrong Voice8Strip the AI tellsYou can spot the phrases no human writes.›
Type this to the agent
Remove every phrase I would never say — delve, unlock, elevate, game-changer, in today's fast-paced world, let's dive in. Rewrite those sentences in plain language.
Wrong Voice9One thought per lineIt has collapsed into dense paragraphs.›
Type this to the agent
Break this into one thought per line the way I write. Short lines. Line breaks where I would pause if I were saying it out loud.
Wrong Voice10Take out the sellIt has slipped into marketing language you would never use.›
Type this to the agent
This sounds like an advert. Take out every phrase designed to persuade and just say what the thing is. Trust the reader to decide.
Wrong Voice11Read it aloudSomething is off and you cannot name it.›
Type this to the agent
Read that back and tell me which sentences a real person would not say out loud. Then rewrite only those, and leave the rest as it is.
Wrong Voice12Match the sampleThe voice guide is not landing.›
Type this to the agent

Length and Shape14Cut the warm-upThe first three lines say nothing.›

Length and Shape15Cut the wrap-upIt ends with a paragraph restating what it just said.›
Type this to the agent
Remove the closing summary. End on the last real point, then one line telling the reader what to do.
Length and Shape16Expand what is thinThe most important section is one line long.›

Length and Shape17Fit the platformIt is the wrong shape for where it is going.›
Type this to the agent

Type this to the agent

Wrong Audience20Remove the jargonIt assumes knowledge your reader does not have.›
Type this to the agent

Wrong Audience21Stop assuming the setupIt assumes tools, budget or a team your reader does not have.›
Type this to the agent

Wrong Audience22Speak to one personIt addresses a crowd.›

Wrong Audience23Name the real problemIt solves a problem your audience does not actually have.›

Wrong Audience24Drop the condescensionIt explains something obvious as though the reader is new to life.›
Type this to the agent

When It Goes Wrong26Keep what workedThe correction risks rewriting the good parts.›

Type this to the agent

Before and After31A content postContent›
Before — what the agent gave you
Consistency is key when it comes to growing your online business.
Many entrepreneurs struggle with staying consistent, but showing up
regularly is what separates those who succeed from those who don't.
Start small, build the habit, and watch your audience grow!
After — the fixed version
I posted every day for six weeks and got 40 followers.
Then I posted twice a week for six weeks and got 300.

The difference was not consistency.
It was that I stopped posting things I did not care about
just to fill a slot.

Posting daily is easy to measure, which is why everyone
recommends it. It is not the thing that works.
Why it worksThe before has no numbers, no position and an exclamation mark. The after commits to something specific that the writer could only say because it happened to her.
